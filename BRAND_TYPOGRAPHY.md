# Path A Logical (PAL) — Typography System

Status: **APPROVED / LOCKED**

This file is a canonical extension of `BRAND_WORKSHOP.md`. It defines the production typography system for **Path A Logical**, with **PAL** as the compact brand identity.

## Brand-name rule

The full brand name is exactly:

# **Path A Logical**

Compact shorthand:

# **PAL**

Do not change the full name to Path A Logic, Path A Logicale, PathLogic, Path-A-Logical, or another variation unless the naming decision is explicitly reopened.

---

# 1. Primary display / brand serif

## Lora SemiBold

Use **Lora SemiBold** for:

- the Path A Logical wordmark direction
- large marketing headlines
- major trip/editorial titles where space allows
- field-guide-style section moments
- occasional large quote or campaign copy

Purpose:

- gives the brand its warm printed-field-guide character
- supports the golden-age camping influence
- keeps the identity classic without looking faux-vintage

Rules:

- do not use Lora for dense lists, maps, settings, forms, or small controls
- do not artificially distress or weather the letterforms
- use normal tracking by default; adjust only for polished wordmark production
- prefer Mud Ink, Evergreen, Warm Cream, or Parchment depending on background

---

# 2. Primary UI / utility sans

## Inter

**Inter** is the default application typeface.

### Approved weights

- **Inter SemiBold** — subheads, tabs, section labels, important compact headings
- **Inter Medium** — buttons, navigation, chips, small control labels
- **Inter Regular** — body copy, metadata, descriptions, checklist rows, settings, map/support text

Purpose:

- clean and highly readable
- handles dense trip-planning information well
- preserves the modern 60% side of the brand system
- provides strong contrast with the warmer Lora display face

### UI rule

If typography ever becomes decorative enough to slow scanning, switch that element back to Inter.

---

# 3. Script / handwritten accent

## Caveat Regular

**Caveat Regular** is the approved clean script-like accent face.

It is a secondary personality tool, not a third general-purpose text family.

### Good uses

Use sparingly for:

- short campaign flourishes
- a brief note beneath a hero headline
- occasional field-note callouts
- low-stakes completion moments
- small editorial annotations
- selected marketing graphics
- rare illustrated-map or field-journal annotations when legibility remains strong

Examples of appropriate length:

- `Adventure is the reason.`
- `Ready when you are.`
- `Worth the extra mile.`
- `Packed and ready.`

### Do not use Caveat for

- buttons
- navigation
- checklist item names
- warnings
- weather data
- safety copy
- map labels
- form fields
- accessibility-critical information
- long paragraphs
- legal/privacy copy
- the primary Path A Logical wordmark

### Script usage limit

A normal product screen should contain **zero or one** script-accent moment.

Most screens should contain none.

The script face should feel like a handwritten margin note in a field guide, not a scrapbook or rustic-sign aesthetic.

# 4. Recommended type scale

These are starting production tokens and may be adjusted slightly for platform conventions without changing the hierarchy.

| Token | Typeface | Weight | Suggested size / line height | Typical use |
| --- | --- | --- | --- | --- |
| Display 1 | Lora | SemiBold | 44 / 52 | Marketing hero / large editorial moment |
| Heading 1 | Lora | SemiBold | 28 / 36 | Major page or trip title |
| Heading 2 | Inter | SemiBold | 20 / 28 | Major UI section heading |
| Subtitle | Inter | SemiBold | 16 / 24 | Card and section subtitle |
| Body | Inter | Regular | 16 / 24 | Default readable body copy |
| Small | Inter | Regular | 14 / 20 | Metadata and secondary information |
| Caption | Inter | Regular | 12 / 16 | Compact support text where accessibility permits |
| Button | Inter | Medium | 14–16 / 20–24 | Buttons and actions |
| Accent note | Caveat | Regular | 20–28 / natural | Short noncritical brand/editorial accent |

Do not force small type merely to preserve layout. Outdoor use, bright sunlight, and quick scanning take priority.

# 5. Typography hierarchy by context

## Main application UI

Default order:

1. Inter
2. Lora for selective major headings
3. Caveat only as optional noncritical accent

## Marketing / landing pages

Default order:

1. Lora for major brand headlines
2. Inter for supporting information and controls
3. Caveat for one restrained handwritten accent when useful

## Maps and field information

Use **Inter** almost exclusively.

Brand personality should come from color, iconography, route styling, topo language, and surrounding surfaces rather than decorative type inside map data.

## Safety / weather / alerts

Use **Inter only** for consequential information.

No Caveat.

Prefer clarity, hierarchy, and strong contrast over brand flourish.

---

# 6. Logo typography relationship

## Full brand

**Path A Logical** remains the dominant readable brand name.

Recommended wordmark direction:

- Lora-derived serif character
- carefully tuned spacing for production logo art
- Evergreen / Mud Ink on light surfaces
- Warm Cream / Parchment on dark surfaces
- PAL may appear beneath or beside it as a small supporting shorthand

Do not turn the full wordmark into a script logo.

## Compact identity

**PAL** remains the compact/app identity.

The PAL monogram should use a strong serif or custom-drawn derivative compatible with the full wordmark. It should not use Caveat.

---

# 7. Accessibility and readability rules

1. Critical information must never depend on Caveat or decorative lettering.
2. Do not place text over topo texture unless contrast remains clear.
3. Avoid low-contrast sage-on-canvas body text.
4. Body copy should generally use Mud Ink on Warm Cream in light mode and Parchment on Night Pine in dark mode.
5. Do not use all-caps for long labels or paragraphs.
6. Use adequate line spacing and touch-target separation around dense checklist content.
7. Preserve platform text scaling and accessibility settings wherever technically possible.
8. Bright-sunlight readability outranks decorative typography.

---

# 8. Final locked typography stack

**Display / brand serif:** Lora SemiBold  
**UI sans:** Inter Regular / Medium / SemiBold  
**Script accent:** Caveat Regular

This combination is the approved Path A Logical typography direction.

The script accent is intentionally minor. The product should still read primarily as a clean, capable planning tool with a restrained field-guide personality.
