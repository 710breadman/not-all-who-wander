# Path A Logical (PAL) — Production Brand Asset Pack

Canonical full brand: **Path A Logical**

Compact/app identity: **PAL**

## Included

- Editable SVG source marks and wordmark lockup
- App icon PNGs from 16 px through 1024 px
- Transparent mark PNG variants
- PWA 192 / 512 icons
- Multi-size favicon.ico and favicon.svg
- Android adaptive-icon foreground master and XML examples
- JSON and CSS implementation tokens
- Locked checklist semantic colors

## Typography

- Display/headings: **Lora SemiBold**
- UI/body: **Inter**
- Script accent: **Caveat Regular**

Font binaries are intentionally not included in this package. During implementation, use appropriately licensed copies from their official source and bundle them locally so the offline-first app does not depend on a network font request.

The script font is an accent only. Do not use it for controls, body copy, warnings, dense data, maps, or long paragraphs.

## Checklist status colors — permanent

- Green `#2F7D4A` = Complete
- Red `#C94A3A` = Missing
- Yellow `#D9A321` = Partial / Maybe
- Gray `#8A8D85` = Not needed

Never communicate state by color alone; pair with icon/shape/text.

## Production note

The logo sources here are implementation-ready clean vector constructions based on the approved visual direction. They are deliberately simpler than the concept-board illustration so they remain legible at small sizes.

Before public release, run final trademark/name/logo-similarity clearance.
