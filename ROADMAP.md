# Roadmap

## Phase 1 — Foundation
Build a local-first, installable application with durable schema and seed data.

## Phase 2 — Core packing
Create trips, generate checklist snapshots, edit quantities, update status, and persist everything.

## Phase 3 — Inventory
Make the reusable master inventory easy to search and maintain.

## Phase 4 — Reliability
Backup/restore, CSV export, migrations, offline testing, and end-to-end tests.

## Phase 5 — UX polish
Packing mode, Need-to-Buy workflow, stronger responsive design, accessibility, and onboarding.

## Phase 6 — Smart trip setup
Optional trip-style presets, richer quantity rules, amenities, weather-informed suggestions.

## Phase 7 — Sync / integrations
Only after the local-first app is excellent:
- cloud sync
- Sheets interoperability
- weather
- maps/location autocomplete
- reservation links

## Phase 8 — Advanced
Potential:
- shared trips
- reusable family/group profiles
- barcode scanning
- AI checklist review
- trip retrospectives that learn from forgotten/unused items
